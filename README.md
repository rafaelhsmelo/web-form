# Questionário Villa Piauhy

Aplicação web para coleta de dados por meio de um questionário interativo multi-etapas, com salvamento contínuo do progresso.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Turso (libSQL/SQLite)

## Configuração

Crie `.env.local` com:

```env
TURSO_DATABASE_URL=
TURSO_AUTH_TOKEN=
ADMIN_KEY=
```
